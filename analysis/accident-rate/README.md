# การวิเคราะห์ Accident Rate ร่วมกับ Accident Severity

ชุดนี้คือการวิเคราะห์จุดเสี่ยง 630 คลัสเตอร์ (ชุด 3 ปี `v2569-r2-3y`, DBSCAN eps 200 ม.) ด้วยอัตราการเกิดอุบัติเหตุ (Accident Rate) และนำผลมารวมกับดัชนีความรุนแรง (SI)

> **สถานะ:** เป็นผลวิเคราะห์สำหรับเล่มรายงาน **ยังไม่ได้นำไปใช้กับแผนที่หรืออุปกรณ์** แผนที่ปัจจุบัน (`data/risk_points_bkk_metro_3y.geojson`) ยังจัดระดับด้วย SI อย่างเดียว

## ผลสรุป

ปริมาณจราจร (AADT ปี 2566–2568) มาจากข้อมูลเปิดของหน่วยงาน ได้ครบ **598 จาก 630 คลัสเตอร์**

| หน่วยงาน (กลุ่มอ้างอิง) | คลัสเตอร์ | Ra |
|---|---|---|
| กรมทางหลวง (ทล.) | 466 | 0.1346 |
| การทางพิเศษแห่งประเทศไทย (กทพ.) | 125 | 0.0194 |
| กรมทางหลวงชนบท (ทช.) | 7 | 0.2021 |

| ระดับ | SI อย่างเดียว | Rate อย่างเดียว | **SI + Rate** |
|---|---|---|---|
| สูง | 27 | 84 | **111** |
| ปานกลาง | 123 | 72 | **167** |
| ต่ำ | 448 | 442 | **320** |

ไม่มีคลัสเตอร์ใดได้ระดับสูงจากทั้งสองวิธี แปลว่าสองวิธีวัดความเสี่ยงคนละมิติ

**32 คลัสเตอร์ที่ไม่มีข้อมูลเปิด** ใช้ระดับจาก SI อย่างเดียว ได้แก่
- สะพานภูมิพล ส.012 และ ส.013 รวม 29 คลัสเตอร์
- ราชพฤกษ์ นบ.3021 ช่วง กม. 11–28 จำนวน 2 คลัสเตอร์
- ทางพิเศษ E006 อาจณรงค์–บางนา จำนวน 1 คลัสเตอร์

ค่าที่อธิบดีกรมทางหลวงชนบทเปิดเผยต่อสื่อ (ภูมิพล 90,303 คัน/วัน · ราชพฤกษ์ 120,000 คัน/วัน) เก็บไว้ในไฟล์ขั้นที่ 3 เป็นข้อมูลเสริม

## วิธีคำนวณ

| ขั้น | สูตร | อ้างอิง |
|---|---|---|
| V | ค่าเฉลี่ย AADT ปี 2566, 2567, 2568 | — |
| MEV | (V / 1,000,000) × T × 365 · T = 3 ปี | AASHTO (2010) HSM สมการ 4-8 |
| R | A × 1,000,000 / (365 × T × V × L) · L = 1 กม. | ณัฐพงศ์ ซื่อสัตย์ (2558) สมการ 3.2 · HSM สมการ 4-9 |
| Ra | Σ(Vᵢ × Rᵢ) / ΣVᵢ คิดแยกตามหน่วยงาน | HSM สมการ 4-10 หน้า 4-43 |
| Rc | Ra + K[Ra / MEV]^0.5 + 1 / (2 × MEV) · K = 1.645 | ณัฐพงศ์ สมการ 3.4 · HSM สมการ 4-11 |
| DF | R / Rc | ณัฐพงศ์ สมการ 3.3 |

### เกณฑ์แบ่งระดับ

| ระดับ | Accident Rate | SI |
|---|---|---|
| ต่ำ | R ≤ Ra | SI < 1 |
| ปานกลาง | Ra < R ≤ Rc | 1 ≤ SI < 2 |
| สูง | R > Rc (DF > 1) | SI ≥ 2 |

- **Rate:** ใช้ลำดับขั้นของ Minnesota DOT (2010) คือเทียบกับค่าเฉลี่ยก่อน แล้วจึงทดสอบอัตราวิกฤติ เกณฑ์ DF > 1 อ้างอิงณัฐพงศ์หน้า 54 และ HSM หน้า 4-12, 4-41 ส่วนการเรียกช่วง Ra–Rc ว่า "ปานกลาง" เป็นการตีความของผู้วิจัย
- **SI:** จุดตัด 1 และ 2 ใกล้เคียง Q3 (0.99) และรั้วบน Q3 + 1.5·IQR (2.05) ตามแนวคิด Box Plot ของ Tukey (1977) และ NIST e-Handbook หัวข้อ 7.1.6
- **ระดับรวม:** ใช้ระดับที่สูงกว่า เพราะเกินเกณฑ์ด้านใดด้านหนึ่งก็ถือว่าเสี่ยง ตาม WisDOT Figure 3 หน้า 9 และข้อเสนอแนะของณัฐพงศ์หน้า 55

รายการอ้างอิงพร้อมเลขหน้าและลิงก์ อยู่ในชีต "อ้างอิงเกณฑ์" ของ `outputs/ระดับจุดเสี่ยง-598คลัสเตอร์-SI+AccidentRate.xlsx`


## ข้อจำกัด

- L = 1 กม. คงที่ทุกคลัสเตอร์ (ตามหน่วยช่วงถนน 1 กม. ของณัฐพงศ์) จึงใช้ R เทียบลำดับระหว่างคลัสเตอร์ ไม่ใช่อัตราต่อกิโลเมตรจริง
- ค่า V ของ ทล. เป็นค่าของสถานีตัวแทนตอนควบคุม ซึ่งบางตอน ทล. กำหนดสถานีของทางหลวงสายอื่นเป็นตัวแทน
- ค่า V ของ กทพ. เป็นยอดผ่านด่านทั้งสาย ไม่ใช่ AADT รายจุด
- กลุ่ม ทช. มีเพียง 7 คลัสเตอร์ ค่า Ra ของกลุ่มจึงไม่เสถียร
