# audio/ — ไฟล์เสียงพูดแจ้งเตือนที่อัดไว้ล่วงหน้า

ไฟล์ mp3 ในโฟลเดอร์นี้คือเสียงพูด 12 ประโยคที่สร้างจาก Botnoi Voice Studio
ระบบจะเล่นไฟล์เหล่านี้ก่อนเป็นชั้นแรก (ดู `VOICE_CLIPS` ใน `js/tts.js`)

## ทำไมต้องอัดไว้ล่วงหน้า

เว็บที่ deploy บน GitHub Pages ไม่มีเซิร์ฟเวอร์ จึงไม่มี `/api/tts`
เสียง Botnoi สดใช้ไม่ได้เลยบนเว็บจริง ต้องตกไปใช้ Google ซึ่งเสียงแข็งกว่ามาก
ไฟล์ที่อัดไว้จึงเป็นทางเดียวที่จะได้เสียง Botnoi บนเว็บจริง
ผลพลอยได้: ไม่เสียพอยท์ต่อการเตือนหนึ่งครั้ง · เล่นทันทีไม่ต้องรอเรียก API · ใช้ได้ตอนไม่มีเน็ต

## วิธีสร้างใหม่ (เมื่อข้อความเตือนเปลี่ยน)

1. สร้างรายการประโยคใหม่จากข้อมูลปัจจุบัน — คำสั่งอยู่ใน README หลัก หัวข้อ "เสียงพูดแจ้งเตือน"
   ได้ไฟล์ `audio-script.txt` บรรทัดละหนึ่งประโยค เรียงจากที่ใช้บ่อยที่สุด
2. เปิด https://voice.botnoi.ai/tts — วางทีละบรรทัดเป็นคนละประโยค (กด "เพิ่มประโยค")
   ใช้เสียงเดียวกันทุกประโยค ไม่งั้นคนขับจะได้ยินเสียงเปลี่ยนคนกลางทาง
3. ดาวน์โหลด: นามสกุล **mp3** + **ดาวน์โหลดไฟล์ Zip** (ห้ามเลือก "รวมเป็นไฟล์เดียว"
   เพราะจะได้เสียงยาวไฟล์เดียวที่พูดทุกประโยคต่อกัน ใช้ไม่ได้)
4. แตก zip แล้วเปลี่ยนชื่อตามลำดับบรรทัดใน `audio-script.txt`
   บรรทัดที่ 1 -> `alert_01.mp3` · บรรทัดที่ 2 -> `alert_02.mp3` · ไปจนถึง `alert_12.mp3`
5. วางไว้ในโฟลเดอร์นี้ แล้ว bump `?v=` ของ `js/tts.js` ใน `index.html`

## ถ้าไฟล์ยังไม่ครบ

ไม่พัง — ไฟล์ไหนไม่มี ระบบจะได้ 404 แล้วไล่ไปชั้นถัดไป
(Botnoi สด -> Google -> Web Speech) ตามลำดับเดิม ทีละไฟล์อิสระกัน

## ⚠️ ไฟล์ที่ต้องอัดใหม่

- **`alert_02.mp3` — ยังขาด** (ใช้กับ 51 คลัสเตอร์ ระดับปานกลางที่เคยมีผู้เสียชีวิต)
  ข้อความใหม่: `ข้างหน้าอีกประมาณ 500 เมตร กรุณาลดความเร็ว และใช้ความระมัดระวัง`
  (~126 พอยท์ · 63 ตัวอักษร)

  ไฟล์เดิมย้ายไปไว้ที่ `audio/outdated/alert_02_old_pen-piset.mp3` เพราะพูดว่า
  "...ใช้ความระมัดระวัง**เป็นพิเศษ**" ซึ่งสงวนไว้ให้ระดับสูงเท่านั้น
  ถ้าปล่อยไว้ที่เดิมระบบจะพูดข้อความผิดระดับ

  ระหว่างที่ยังไม่มีไฟล์ ระบบจะตกไปใช้ TTS สด (Google) ซึ่งพูดข้อความที่ถูกต้อง
  แต่เป็นคนละเสียงกับไฟล์อื่น
