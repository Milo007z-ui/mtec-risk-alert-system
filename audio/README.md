# audio/ — ไฟล์เสียงพูดแจ้งเตือนที่อัดไว้ล่วงหน้า

ไฟล์ mp3 ในโฟลเดอร์นี้คือเสียงพูด 12 ประโยคที่สร้างจาก Botnoi Voice Studio
ระบบจะเล่นไฟล์เหล่านี้ก่อนเป็นชั้นแรก (ดู `VOICE_CLIPS` ใน `js/tts.js`)

## ทำไมต้องอัดไว้ล่วงหน้า

เว็บที่ deploy บน GitHub Pages ไม่มีเซิร์ฟเวอร์ จึงไม่มี `/api/tts`
เสียง Botnoi สดใช้ไม่ได้เลยบนเว็บจริง ต้องตกไปใช้ Google ซึ่งเสียงแข็งกว่ามาก
ไฟล์ที่อัดไว้จึงเป็นทางเดียวที่จะได้เสียง Botnoi บนเว็บจริง
ผลพลอยได้: ไม่เสียพอยท์ต่อการเตือนหนึ่งครั้ง · เล่นทันทีไม่ต้องรอเรียก API · ใช้ได้ตอนไม่มีเน็ต

## วิธีสร้างใหม่ (เมื่อข้อความเตือนเปลี่ยน)

1. สร้างรายการประโยคใหม่จากข้อมูลปัจจุบัน — คำสั่งอยู่ใน README หลัก หัวข้อ "เสียงพูดแจ้งเตือน"
   ได้ไฟล์ `audio-script.txt` บรรทัดละหนึ่งประโยค เรียงจากที่ใช้บ่อยที่สุด
2. เปิด https://voice.botnoi.ai/tts — วางทีละบรรทัดเป็นคนละประโยค (กด "เพิ่มประโยค")
   ใช้เสียงเดียวกันทุกประโยค ไม่งั้นคนขับจะได้ยินเสียงเปลี่ยนคนกลางทาง
3. ดาวน์โหลด: นามสกุล **mp3** + **ดาวน์โหลดไฟล์ Zip** (ห้ามเลือก "รวมเป็นไฟล์เดียว"
   เพราะจะได้เสียงยาวไฟล์เดียวที่พูดทุกประโยคต่อกัน ใช้ไม่ได้)
4. แตก zip แล้วเปลี่ยนชื่อตามลำดับบรรทัดใน `audio-script.txt`
   บรรทัดที่ 1 -> `alert_01.mp3` · บรรทัดที่ 2 -> `alert_02.mp3` · ไปจนถึง `alert_12.mp3`
5. วางไว้ในโฟลเดอร์นี้ แล้ว bump `?v=` ของ `js/tts.js` ใน `index.html`

## ถ้าไฟล์ยังไม่ครบ

ไม่พัง — ไฟล์ไหนไม่มี ระบบจะได้ 404 แล้วไล่ไปชั้นถัดไป
(Botnoi สด -> Google -> Web Speech) ตามลำดับเดิม ทีละไฟล์อิสระกัน

## alert_02.mp3 สร้างโดยตัดจากไฟล์เดิม (ไม่ได้อัดใหม่)

ตอนแก้คำเตือนระดับปานกลางให้เลิกใช้คำว่า "เป็นพิเศษ" ข้อความใหม่กลายเป็น
"ส่วนต้น" ของข้อความเดิมพอดี จึงตัดคำท้ายออกแทนการอัดใหม่ ประหยัดไป ~126 พอยท์
และได้เสียงคนเดียวกับไฟล์อื่นแน่นอน

    เดิม  ...กรุณาลดความเร็ว และใช้ความระมัดระวังเป็นพิเศษ   (6.30 วินาที)
    ใหม่  ...กรุณาลดความเร็ว และใช้ความระมัดระวัง            (5.47 วินาที)

หาจุดตัดจากซองพลังงานเสียง เจอช่วงเงียบสนิท (-63 dB) ที่ 5.42-5.50 วินาที
ซึ่งเป็นรอยต่อระหว่าง "ระมัดระวัง" กับ "เป็นพิเศษ" จึงตัดที่ 5.47 วินาที
พร้อม fade out 60 ms กันเสียงขาดห้วน

ตรวจว่าตัดถูกจุดด้วยสามทาง:
  - พลังงาน 50 ms สุดท้ายอยู่ที่ -54.6 dB = จบในช่วงเงียบ ไม่ได้ตัดกลางคำ
  - อัตราการพูด 0.0868 วินาที/ตัวอักษร เทียบค่าเฉลี่ยไฟล์อื่น 0.0881 ต่างเพียง 1.4%
  - ความยาวที่ได้ตรงกับที่ประมาณจากสัดส่วนตัวอักษร (63/72 x 6.30 = 5.51 วินาที)

ไฟล์ต้นฉบับเก็บไว้ที่ `audio/outdated/alert_02_old_pen-piset.mp3`

**เทคนิคนี้ใช้ซ้ำได้** เมื่อข้อความใหม่เป็นส่วนต้นของข้อความเดิม — ไม่ต้องเสียพอยท์
ถ้าข้อความเปลี่ยนตรงกลางหรือต้นประโยคต้องอัดใหม่เท่านั้น


## ข้อความเปลี่ยนทั้ง 12 ไฟล์ — เพิ่ม "จุดเสี่ยงระดับ" (2026-08-25)

ของเดิมตั้งใจไม่พูดชื่อระดับตรง ๆ (สื่อความเร่งด่วนด้วยน้ำหนักคำแทน) ผู้ใช้ขอให้
พูดระดับชัดเจนกว่านี้ จึงเติม "จุดเสี่ยงระดับต่ำ/ปานกลาง/สูง" เข้าไปทุกประโยค
พร้อมคงคำสุภาพ "กรุณา"/"ขอให้" ไว้ตามเดิม (เลือกจาก 3 แบบที่เสนอ)

**ต้องอัดใหม่ทั้ง 12 ไฟล์** ไม่ใช่แค่ไฟล์ที่ยังไม่เคยอัด — ไฟล์เดิม 6 ตัวที่อัดไปแล้ว
ก่อนเปลี่ยนคำ (alert_04, 05, 06, 10, 11, 12) ใช้ข้อความรุ่นก่อนหน้า ไม่ตรงกับ
VOICE_CLIPS ชุดใหม่แล้ว ต้องอัดทับใหม่ทั้งหมด

ประโยคชุดใหม่ทั้ง 12 อยู่ใน `js/tts.js` (`VOICE_CLIPS`) เป็นต้นทางเดียว —
คัดลอกจากตรงนั้นไปวางที่ Botnoi ได้เลย ห้ามพิมพ์มือซ้ำเพราะเสี่ยงพิมพ์ตกตัวอักษร
แล้วไฟล์เสียงจะ match ข้อความไม่ติด (ระบบจะเงียบ ๆ ตกไปใช้ TTS สดแทนโดยไม่มี error)
